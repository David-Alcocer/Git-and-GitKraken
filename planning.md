# Curso Básico: Git & GitHub con GitKraken desde Cero
**Dirigido a:** Estudiantes de nuevo ingreso

**Duración:** 4.5 horas efectivas 

**Modalidad:** 100% visual, usando GitKraken como cliente gráfico y VS Code como editor de código

**Distribución:** ~115 min trabajo individual · ~120 min trabajo en equipos · ~55 min teoría y cierre
 
## Contenidos

- El alumno conocerá la herramienta del control de versiones que le permitirá organizar y administrar su código mediante Git y GitKraken.

- El alumno conocerá, creará y clonará un repositorio de un proyecto.

- El alumno también aprenderá las acciones push y pull para sincronizar cambios con GitHub.

- El alumno conocerá las maneras de poder corregir merge conflicts 


 
## Requisitos previos
- Laptop con GitKraken instalado
- VS Code instalado
- Cuenta de GitHub creada previamente
- Cuenta de correo verificada (no es necesaria el student developer pack)
---
 
## Agenda
 
### Bloque 1 — Introducción (20 min) — Teoría (canva)
- ¿Qué es el control de versiones y por qué existe?
- Git vs. GitHub: la herramienta vs. la plataforma
- ¿Por qué GitKraken? (ver visualmente lo que pasa "por dentro")

### Bloque 2 — Setup rápido + tour de interfaz (20 min) — Teoría
- Instalar GitKraken y conectar cuenta de GitHub (antelación)
- Configurar nombre y correo (antelación)
- Tour rápido: panel de commits, gráfico, barra lateral

### Bloque 3 — Conceptos fundamentales (15 min) — Teoría (mostrar GitKraken)
- Repositorio (repo)
- ¿Qué es un commit? Anatomía de un commit (autor, mensaje, hash)
- El grafo de commits: cómo leerlo

### Bloque 4 — Primer repositorio + commits (40 min) 🖐️ Individual
- Crear un repo nuevo desde GitKraken (deben crear una carpeta)
- Modificar archivos en VS Code, hacer stage y escribir mensajes de commit
- Ejercicio: realizar 3–4 commits y ver el gráfico crecer

### Bloque 5 — Ramas (branches) visualmente (50 min) 🖐️ Individual
- ¿Qué es una rama? (analogía de "línea de tiempo alterna")
- Crear una rama nueva y cambiar entre ramas (checkout)
- Fusionar (merge) visualmente y observar el gráfico unirse
- Ejercicio: crear una rama, hacer cambios y fusionarla a main

**☕ Descanso (10 min)**

### Bloque 6 — Trabajo remoto: push y pull (25 min) 🖐️ Individual
- ¿Qué es un remoto (remote)? origin y GitHub
- Push: subir cambios / Pull–Fetch: traer cambios
- Ejercicio: subir el repo de práctica a la cuenta personal de GitHub

### Bloque 7 — Colaboración: Fork + Pull Request (45 min) 👥 Equipos
- Fork: copiar un repo (el del instructor y del compañero)
- Pull Request (PR): cómo proponer cambios
- Revisar y comentar un PR (breve intro a Issues)
- Ejercicio: hacer fork del repo del instructor y mandar un PR que otro equipo revisa

### Bloque 8 — Resolviendo conflictos en equipos (40 min) 👥 Equipos
- ¿Qué es un conflicto y por qué ocurre?
- Usar el resolutor visual de conflictos de GitKraken
- Ejercicio guiado: provocar y resolver un conflicto simple entre dos integrantes del equipo

### Bloque 9 — Mini proyecto integrador (35 min) 👥 Equipos
- Reto en equipos: clonar un repo, crear una rama, hacer cambios, subir la rama y mandar un PR que otro equipo revisa y aprueba

### Cierre (20 min) — Plenaria
- Recapitulación del flujo completo
- Recursos para seguir practicando (GitHub Learning Lab, Oh My Git!, etc.)
- Preguntas abiertas
